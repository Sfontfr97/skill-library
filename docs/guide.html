A Claude Code mod, version 0.4.0

Skill library

See every skill you have, grouped by what it does, and drop one into the prompt with one click, without remembering its name.

Install

The mod is a folder. You keep it on your computer and tell Claude Code where it is. It takes about two minutes, and you need Claude Code already set up.

  1. Download and unzip it. On github.com/Sfontfr97/skill-library, click Code, then Download ZIP. Unzip it, rename the folder to skill-library if it ends in -main, and move the folder somewhere it can stay, such as a Tools folder in your home folder. Claude reads it from there every time, so don't leave it in Downloads.

  2. Copy the folder's path. On a Mac, select the folder in Finder, hold option, open the right-click menu and choose Copy "skill-library" as Pathname. It looks like this:

    /Users/your-name/Tools/skill-library

  3. Tell Claude Code where it is. Pick how you use Claude Code.

    Desktop app

    Open ~/.claude/settings.json in any text editor (in Finder, press cmd+shift+g and paste ~/.claude). Add this line inside the env block, with your own path. If the file has no env block, add the whole thing:

    "env": {
  "CLAUDE_CODE_PLUGIN_DIRS": "/Users/your-name/Tools/skill-library"
}

    Already have CLAUDE_CODE_PLUGIN_DIRS? Add this path to it, separated by a colon (a semicolon on Windows). Then quit and reopen the app.

    Terminal

    Start Claude with the folder each time. Or add the same env line above, and every session loads it.

    claude --plugin-dir ~/Tools/skill-library

  4. Check it works. Type /skill-library in the prompt. You should see "Skill library is above the prompt." and the library just above it. If the command doesn't exist, the path is wrong or the app wasn't restarted.

Updating to a new version

Replace the folder with the new one, in the same place, and start a new session. Your names, types, hidden skills and Most used counts are kept, since they don't live in the folder.

Removing it

Delete the path from settings.json and restart. You can then delete the folder.

Quick start

  1. Open it. Type /skill-library. The library opens just above the prompt. The same command closes it.

  2. Find a skill. Start typing in the search field, or pick a type tab such as Review or Write. Show switches between your own skills and your plugins'.

  3. Use it. Press Use. The skill goes to the start of your prompt and the library closes. Add what you want done and send it.

  4. Make it yours. Press the pencil on any row to rename a skill, fix its type, or hide one you never use.

The band

This is the library as it appears in the desktop app. The numbers match the list below it.

Find a skill

By where it comes from

Show opens on Mine, the skills in your own ~/.claude/skills folder. Everything adds the skills of every plugin you installed, and each plugin also has its own entry, largest first. Hidden appears last once you hide a skill. With only one source, Show is not drawn at all.

By what it does

Every skill gets one of five types, guessed from its name and then its description:

TypeWords that place a skill there
Reviewreview, audit, QA, evaluate, debug, troubleshoot, accessibility, declutter, optimize
Writewrite, rewrite, copy, message, email, document, report, summary, handoff, spec
Exploreexplore, research, options, direction, brainstorm, compare, ideas
Buildbuild, create, generate, implement, prototype, component, diagram, library
Otheranything none of the above match

The guess is sometimes wrong. You can set the type yourself in Edit.

By searching

Type in the search field and the list filters right away, across every source (Show switches to Everything while you search). Results are ranked so the skill you mean comes first:

  1. The name starts with what you typed.

  2. The name, or the name you gave it, contains it.

  3. The one line summary on the row contains it.

  4. The plugin name contains it, so figma finds every Figma skill.

  5. It only appears somewhere in the full description.

Press ×, or Enter, to clear the search.

Use a skill

Use puts /skill-name at the start of the prompt and keeps anything you had already typed after it. If the prompt already starts with a slash command, Use replaces it. The band then closes, since your pick is in the prompt. Plugin skills show a short name on the row (/a11y-debugging), and Use still types the full one (/chrome-devtools-mcp:a11y-debugging).

Each pick also counts toward Most used: the three skills you pick most sit at the top of Mine, and leave their type group so nothing appears twice. A tie goes to the one you used last.

The band shows 8 skills at first. Load more at the bottom adds 8 more.

Edit, retype, hide

The pencil (the word Edit in a terminal) opens a small form on that row. Nothing changes until you press Save, or Enter in a field. Cancel drops what you typed.

  • Name shows on the row in place of the command. The real command still shows next to it, dimmed, and Use still types it.
  • Description replaces the one line summary.
  • Type moves the skill to another tab. Automatic shows the guess and goes back to it.
  • Hide takes the skill out of every list and the search, right away. Find it again under Show, Hidden, and press Unhide there.
  • Reset appears once you changed something, and puts the skill back as it was.
Your skill files stay untouched.

Edits are labels kept by the mod. The SKILL.md files, and what Claude reads from them, never change.

Side panel

The band above the prompt can only grow as tall as the app allows. For a roomier view, press Expand: the same library opens as a full-height side panel and shows up to 40 skills at once. The panel stays open after Use, since it does not cover the prompt. Collapse puts it back above the prompt. On a narrow window the panel cannot open, and a short message says so.

What it reads and keeps

WhatWhere
Your skillsEach folder in ~/.claude/skills with a SKILL.md
Plugin skillsThe newest installed version of each plugin, under ~/.claude/plugins/cache
Names, descriptions, types, hiddenThe mod's own storage on your machine, kept across sessions
Most used countsThe same storage: how many times you picked each skill, and when last

Nothing leaves your machine, and the mod never writes to a skill or plugin folder. The library reads the folders each time you open it, so a new skill shows up the next time you run /skill-library.

Desktop and terminal

The library works in both, and adapts to what each can draw.

Desktop appTerminal
Icons and motionType icons, a moving spark, small hover movesThe ✻ mark in clay, no icons
Edit and clear✎ and ×The words Edit and Clear
Number keysNoneRows 1 to 9 answer their number, shown as 1: Use
ScrollingThe whole band scrolls, tabs includedThe tabs stay put and the list scrolls under them

In a terminal, focus the band with a click or ctrl+x then tab, and collapse it with ctrl+x then ctrl+a. All motion stops when your system is set to reduce motion.

Questions

I ran the command and see "No skills yet".
The mod found no folder with a SKILL.md in ~/.claude/skills and no plugin skills. Add one, then run /skill-library again.
Where are docx, pdf and the other built-in skills?
The skills that come with Claude live in a private folder of the app, so this version does not list them yet. They still work from the / menu.
A skill is under the wrong type.
Open the pencil on its row, pick the right Type, and Save.
I hid a skill by mistake.
Set Show to Hidden, open the pencil on its row, and press Unhide.
Most used is empty.
It fills as you pick skills with Use. Picks from before version 0.4.0 were not counted.
Can a teammate see my names, types or counts?
No. They are stored on your machine, for you only.
